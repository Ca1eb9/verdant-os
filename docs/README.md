# docs

If you're new to the project, start here before touching any code.

**Suggested contents:**
- `architecture.md` — how the web app, Pi services, and firmware communicate
- `wiring/` — circuit diagrams and pin mappings
- `setup.md` — how to get a fresh Pi or device up and running
